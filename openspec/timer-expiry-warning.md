# Предупреждение перед окончанием таймера

## Зачем

Пользователь должен заранее услышать, что Agent Awake скоро перестанет удерживать Mac, и успеть продлить таймер до возможного сна.

## Поведение

- Только для режима с конкретным сроком приложение отслеживает последнюю минуту.
- При первом наблюдении активного срока с остатком от 1 до 60 секунд включительно один раз звучит системный `Funk`.
- Повторные тики для того же срока не запускают звук снова.
- Новый или продлённый срок считается новым таймером и может предупредить снова.
- Истёкший срок и режимы без конкретного срока не запускают предупреждение.

## Definition of Done

Пользователь получает один различимый звуковой сигнал за 60 секунд до окончания таймера и может продлить удержание; это подтверждено тестом публичного контроллера срока, release-сборкой и установленной локальной версией приложения.

**Анти-критерий:** один и тот же срок не должен проигрывать предупреждение повторно на следующем тике.

**Стоп-условие:** не завершать работу, пока тесты, release-сборка, `scripts/verify.sh` и проверка установленного процесса не зелёные.

## Проверка человеком

Запустить таймер на 1 минуту: `Funk` должен прозвучать один раз, а не повторяться. Затем запустить новый таймер на 1 минуту: один новый `Funk` должен прозвучать снова.
